## TLDR Workflow

1. Pick or create an issue to claim your task and avoid overlapping work.

2. Code and commit all your work directly to your designated personal branch.

3. Open a Pull Request from your personal branch to main once a feature is ready.

4. Get one approval from a teammate to ensure the code is ready for the main build.

5. Merge the PR into main and immediately notify the team to pull the updates.

6. Sync your branch by pulling the latest main back into your personal branch before starting the next task.
